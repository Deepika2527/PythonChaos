Comprehensions in Python

Comprehensions in Python allow us to write code in a shorter and more readable way to create collections.

Python supports three types of comprehensions:

List Comprehension

Dictionary Comprehension

Set Comprehension


ListComprehension

A list is a built-in data structure used to store multiple items in a single variable.
List Comprehension is a shorter way of creating lists in Python.
It creates a new list by iterating over an iterable and applying an expression to
 each item.
